# SimplePasswordGenerator

## Password Generator

My first Python project: a simple and secure random password generator with a graphical user interface (GUI).

Uses Python's `secrets` module to generate passwords with cryptographically secure randomness and Tkinter to provide a simple graphical interface.

## Features

- Generates passwords of a user-defined length
- Uses uppercase letters, lowercase letters, numbers, and symbols
- Uses cryptographically secure random generation
- Validates user input to ensure a positive whole number is entered
- Displays generated passwords in the GUI
- Copies generated passwords to the clipboard

## How to Run

1. Install Python
2. Clone this repository
3. Run:

```
   python password-generator.py
```
